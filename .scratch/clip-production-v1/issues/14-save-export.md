# 14: 編集を明示保存し、完成動画を書き出す

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/14

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 利用者が編集を保存し、内容を反映した完成動画を出力できる。

**Blocked by:** 11: 編集可能な字幕をAviUtl2へ渡す; 12: アプリからAviUtl2の画面と字幕を編集する; 13: 補助素材を追加して配置する

**Status:** ready-for-agent

## 完了条件

+- [ ] 未保存で閉じる・書き出す際に仕様の選択肢を示し、保存失敗時は内容を保持して書き出しを始めない。
- [ ] 保存は前後状態・更新の安定・内容読取りで、出力は予定長・フレーム数等も加えて簡易判定し、不確実なら成功と断定しない。
- [ ] 横・ショート、音声48kHz、SDR、fps別ビットレートの初期値と変更可能な設定を反映する。補助音声がはみ出しても最後の映像の終了までを出力する。
- [ ] ショート条件外では書き出し時に二択を示し、通常動画を選んでも現在の比率・配置・長さ・設定を変えない。
- [ ] 出力中は同じプロジェクトへの編集を待ち、完了または中止後に再開する。
