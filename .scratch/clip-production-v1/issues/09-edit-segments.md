# 09: 切り出し区間の候補を作り、映像を見て修正する

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/9

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 利用者が発話・非発話・不明の映像を確認して切り出し区間を確定できる。

**Blocked by:** 04: 取得・登録動画を編集可能な媒体へ整える; 06: 対象話者の発言を文字起こしする

**Status:** ready-for-agent

## 完了条件

- [x] 連続した判定区間から候補を作り、処理窓や短い間隔だけで自動結合しない。前後各5秒の初期余白を別々に変更できる。
- [x] 再生確認、境界修正、分割、区間結合、手動追加ができる。区間結合は間の映像を含む。
- [x] 手で直した境界に余白を再加算せず、非発話・不明区間も選択できる。
- [x] 確定操作を自動保存し、失敗時は入力を保持して再試行できる。再生成一覧は別版として保持し、使用版を選べる。

## 実装・検証

- 文字起こし版から同じ判定の隣接窓だけを連結し、前後余白を個別適用する。余白同士が重なっても別候補にする。
- 切り出しタブから映像再生、境界修正、分割、結合、手動追加、採否変更を行う。解析なしの手動作成にも対応した。
- 確定ごとに `catalog/<動画名>/segments/<動画名>_vN.csv` へ別版保存する。保存失敗時は入力を保持し、再試行可能にした。保存版を選択して使用できる。
- `tests.test_segments` の3件は成功。全27件中25件成功、2件は実行環境に SudachiPy と SudachiDict-core が無いため既存の頻出語テストが停止した。GUIの人手操作による確認は未実施。
