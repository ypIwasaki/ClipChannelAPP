# 03: URLから動画・音声成果物を取得する

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/3

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 利用者が認証不要のURLから動画を取得し、成功分と失敗分を把握できる。

**Blocked by:** 01: データ用フォルダを選んで既存データを開く

**Status:** ready-for-agent

## 完了条件

+- [ ] 主要設定と追加引数、機能案内を表示し、保存・上書き・秘密値など保護条件に反する指定は理由を示して実行前に止める。
- [ ] 複数項目は動画ごとに登録し、成功分を保持して失敗項目だけ再試行できる。
- [ ] 情報取得は結果を表示し、音声のみの結果は動画素材にせず音声成果物として残す。
- [ ] 状態・処理時間・通常中止を表示し、停止結果を確認できる。
