# 06: 対象話者の発言を文字起こしする

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/6

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 選んだ人物の発言と時刻を取得し、対象話者の発話・非発話・不明を確認できる。

**Blocked by:** 04: 取得・登録動画を編集可能な媒体へ整える; 05: 人物と参照音声を登録・選択する

**Status:** ready-for-agent

## 完了条件

- [x] 他者の発言を対象話者の成果物に混ぜず、不明区間を残して試聴できる。
- [x] 元動画上の開始・終了時刻と本文を保持し、結果をCSVへ保存・再表示できる。
- [x] 再解析は旧版を上書きせず別版で保存する。
- [x] 今回指定された別動画の0:55〜1:30から、アナウンサーAの人物特徴を生成・保存・再読込できる。
- [ ] 処理の状態・中止と、必要な依存物が不足した場合の停止を確認する。

2026-09-24の利用者変更：初版の今回の動作確認では、指定区間から音声特徴を抽出できればよい。ゲーム音・BGMを含む素材と、対象者のみ・他者のみ・声の重なりの短区間による照合は素材の用意が難しいため不問とする。これは話者識別精度を確認した意味ではない。

## 実装・検証

- 登録済み動画と選択済み人物を用い、同じ ECAPA モデルの照合スコアを5秒単位で表示する。スコアだけでは本人を確定できないため全区間を「不明」で開始し、試聴後に利用者が対象発話・非発話・不明を指定する。対象発話と指定した区間だけをローカル Whisper で認識する。認識結果の発言時刻は元動画時刻へ戻し、未認識部分は不明として残す。
- ffmpeg、ECAPA モデル、Torch・SpeechBrain・numpy、ローカル Whisper モデル、faster-whisper が不足した場合は保存前に停止する設計とした。解析の状態と通常中止操作を表示する。実環境での中止と依存不足の動作確認は未実施。保存済みの人物情報やCSVの閲覧は推論依存物なしで可能。
- CSV は `catalog/<動画名>/transcripts/<動画名>_vN.csv` に保存し、旧版を保持する。選択中のCSVから判定一覧を再表示できる。保存・再読込・版保持・他者本文の拒否を自動テストで確認した。
- 試聴した区間を指定時刻で分割し、対象発話に本文と元動画上の開始・終了時刻を修正・追加できる。重なりを含む5秒窓は分割して確認する。編集後は保存操作で新しい版を作る。自動保存は後続の Issue 07 で扱う。
- 話者判定の品質は既存の複数人検証では確定していない。今回の動作確認ではその品質照合を合格条件にしない。
