# 04: 取得・登録動画を編集可能な媒体へ整える

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/4

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 利用者が取得・登録した通常のSDR動画を、正しい時刻で後続の解析と編集に使える。

**Blocked by:** 02: ローカル動画を登録する; 03: URLから動画・音声成果物を取得する

**Status:** ready-for-agent

## 完了条件

- [x] 形式と実ファイルの映像・音声開始位置を確認し、元動画時刻との対応を維持する。
- [x] 必要な場合は元を保持したまま編集互換ファイルを別に作る。
- [x] 変換失敗後も取得済みファイルを保持し、変換だけ再試行できる。

## 実装・検証

- `ffprobe` で元動画と変換後のストリーム開始時刻を読み、各成果物のJSONに元動画との対応を保存する。
- 互換変換が必要な動画は元動画を残して別のMP4を作る。再試行時のMP4とJSONも別ファイルにする。
- 取得・登録の両経路から媒体準備を実行できる。登録済み動画を選んで変換だけ再試行できる。
- 合成SDR素材で映像・音声の開始差と元ファイル保持、失敗後の再試行を確認した。実際のAviUtl2での読込み確認は後続の編集連携Issueで行う。
