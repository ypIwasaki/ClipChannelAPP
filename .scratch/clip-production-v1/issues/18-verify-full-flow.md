# 18: 同じ素材で一連の制作を確認する

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/18

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 利用者が同じ元動画を使い、取得または登録から完成動画までの一連の制作を確認できる。

**Blocked by:** 07: 文字起こしと不明区間を手修正する; 08: 頻出語から該当発言を確認する; 09: 切り出し区間の候補を作り、映像を見て修正する; 11: 編集可能な字幕をAviUtl2へ渡す; 14: 編集を明示保存し、完成動画を書き出す; 17: 別編集を作って旧編集を保持する

**Status:** ready-for-agent

- [x] 頻出語から発言確認を行い、個別機能の既存確認例と照合する。
- [x] 素材・区間、対象版・設定、各工程の入力・期待値・実結果、保存先・完成動画、未検証範囲を対応付けて記録する。
- [x] 部分検証だけを製品完成と扱わず、合意済みの模擬失敗件数の上限を守る。
