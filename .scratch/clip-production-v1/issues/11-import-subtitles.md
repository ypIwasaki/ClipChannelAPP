# 11: 編集可能な字幕をAviUtl2へ渡す

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/11

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 利用者が元の文字起こしに対応した字幕をAviUtl2で編集できる。

**Blocked by:** 07: 文字起こしと不明区間を手修正する; 10: 区間を選び、順番を決めて編集用動画を作る

**Status:** ready-for-agent

## 完了条件

- [x] 最終クリップ範囲と重なる対象発言だけを結合後の時間軸へ写し、表示時刻を範囲内に収める。
- [x] 字幕を焼き込まず編集可能なオブジェクトとして生成し、本文・件数・時刻・配置を確認する。
- [x] 字幕の編集は元の文字起こしへ反映せず、再取込みは別字幕として追加する。

## 実装・検証

- 保存済み文字起こしの対象発言を、選択・再配置した区間と交差する部分だけ編集用動画のフレームへ写す。取込みファイルは別版で保存し、元CSVは変更しない。
- AviUtl2 2.1.9の実機で2字幕を取り込み、保存した`.aup2`内の本文、0–29・30–59フレーム、Y=350を確認した。同じファイルを再取込みすると、既存字幕を残したまま別レイヤーに2字幕が増えた。
- Pythonの全33テストに成功。AviUtl2プラグインもWindows C++環境でビルドした。
