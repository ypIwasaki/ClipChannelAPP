# 10: 区間を選び、順番を決めて編集用動画を作る

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/10

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 利用者が選択区間と順番から一本の編集用動画を作れる。

**Blocked by:** 09: 切り出し区間の候補を作り、映像を見て修正する

**Status:** ready-for-agent

## 完了条件

- [x] 全区間または選択区間を指定順に使用し、同じ区間を複数回使える。通常のトリミングには解析を必須としない。
- [x] 編集用MP4をH.264/AAC-LCで作り、元動画優先の設定と可変fps時の固定fps選択を反映する。
- [x] 指定時刻に最も近いフレーム境界と差を示し、フレーム単位で調整できる。映像・音声の継ぎ目を確認する。
- [x] 区間と順番を表す名前で編集ごとに別保存し、同名再生成でも旧版を上書きしない。

## 実装・検証

- 切り出し区間の選択・並べ替え・繰り返しから編集用動画を生成し、解析なしの手動区間も使用できる。
- 実フレーム時刻から最近接境界と差を示し、前後の実フレームに調整する。可変fpsは固定fps指定を必須にする。
- 元動画の解像度・映像ビットレート・音声サンプルレートを優先し、`media/edits/<編集フォルダ>/` に区間と順番を含む名前で別保存する。
- 合成後の映像フレーム時刻と音声の継ぎ目をテストし、完成動画をアプリから再生できる。全30件のテストが成功した。
