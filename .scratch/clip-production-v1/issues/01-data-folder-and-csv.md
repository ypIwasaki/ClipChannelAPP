# 01: データ用フォルダを選んで既存データを開く

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/1

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 利用者が直接接続されたドライブのデータ用フォルダを指定し、そこに保存された情報を再表示できる。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## 完了条件

- [x] 規定のフォルダ構成を作成し、既存のデータ用フォルダへ切り替えられる。
- [x] 処理中または未保存入力がある間は切り替えを止め、理由を表示する。
- [x] CSVの列、文字コード、時刻、引用符・改行、版の識別、保存中断時の扱いを決め、保存・再読込みで確認する。
- [x] 依存物が不足しても保存済み情報は閲覧できる。

## 実装・検証

- CSV v1 の形式と保存中断時の扱いを `docs/implements/data-folder-csv.md` に固定した。人物・登録語・除外語と解析結果を画面で再表示できる。
- フォルダ切り替え禁止、版と同名別動画の保護、改行・引用符の往復、保存中断後の旧版保持を自動テストで確認した。全15テストが通過した。
- Windows ドライブ上の F1→F2→F1 の保存・再読込みを WSL から確認した。画面では利用者が確認用 F1・F2 の保存済み情報（7件・6件）、F1 の旧版と改行・引用符を含む本文の再表示を確認した。人物 CSV の参照音声・特徴ファイルは意図的に未配置のまま閲覧できた。
