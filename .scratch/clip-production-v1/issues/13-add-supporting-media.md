**Blocked by:** 10: 区間を選び、順番を決めて編集用動画を作る; 12: アプリからAviUtl2の画面と字幕を編集する

**Status:** ready-for-agent

## 完了条件

- [x] 外部の補助素材をデータ用フォルダへコピーし、元ファイルを変更しない。
- [x] 配置を編集用動画に紐づけ、アプリから調整・プレビューできる。
- [x] BGMは区間の継ぎ目を越えられ、追加時に長さを勝手に変えない。

## 実装・検証

2026-09-25: 依存先 Issue 10・12 の完了条件チェック、実装コミット、検証記録を確認して着手した。

- 「補助素材」タブで画像（PNG/JPEG/BMP）・BGM・効果音をコピーし、開始フレーム・長さ、画像位置・拡大率、音声の素材開始秒・音量を調整する。素材は `media/supporting/<編集フォルダ>/<素材識別子>/` に別保存し、配置指示 `.ccmedia` は対応する `projects/<編集フォルダ>/` に版を分けて保存する。新しい編集用動画へ既存配置を移さない。
- アプリからAviUtl2の排他的な編集セクションへ適用し、同じ配置の更新時は重複追加しない。AviUtl2の画像と、指定位置から最大5秒のミックス音声をアプリで確認できる。
- BGMの全長をフレーム単位で保持し、区間の継ぎ目・映像終端では切り詰めない。プレビュー音声とAviUtl2の選択範囲は編集用動画の終端までとする。完成動画の保存・出力制御は Issue 14 に残す。
- `python -m unittest discover -s tests -v`: 41件中40件成功、Windows専用の実機テスト1件はWSLではスキップ。専用テストをWindows/AviUtl2 2.1.9で別途実行して成功した。日本語名の画像の取込み、移動・拡大率と重複防止、6秒BGMを4秒動画へ追加した際の全長保持、2秒の継ぎ目を越える再生、素材開始秒・音量変更、効果音のミックス、プレビュー音声の終端を確認した。
- Windowsでも補助素材APIの4件と未適用入力のGUI回帰テストが成功。画面構築と補助素材タブの操作ボタンの表示を確認した。新規PythonモジュールとブリッジのPyrightはエラー0件、プラグインはMSVCでビルド成功。
- レビュー基準は着手時の `89d79a4`。規約・仕様を別エージェントでレビューし、未適用入力がフォルダ切替で失われる指摘を修正した。追加・変更の未適用状態を保持し、切替と新規編集を止め、明示的な入力破棄を用意した。テスト補助関数の命名指摘も修正済み。未解決の指摘はない。
- 初回の実装・検証完了時点では変更をローカルコミットに留めた。以降の公開結果は下記を参照。
