# 05: 人物と参照音声を登録・選択する

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/5

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 利用者が名前付き人物の参照音声を登録し、別動画の対象話者として再利用できる。

**Blocked by:** 01: データ用フォルダを選んで既存データを開く; 02: ローカル動画を登録する

**Status:** ready-for-agent

## 完了条件

- [x] 音声ファイルとアプリ内動画の指定区間の双方から参照音声を登録でき、試聴・選択できる。
- [x] 人物情報をフォルダ内のCSV、参照音声・特徴ファイルを別ファイルとして保存・再表示できる。
- [x] 人物データの選択とモデル・閾値・分割方法を実装時に確認し、別動画で再利用できる。

## 実装・検証

- [人物と参照音声の保存契約](../../../docs/implements/person-reference.md)にモデル、閾値、分割方法とファイル配置を記録した。
- 同じ人物を別の登録済み動画にも対象話者として選び、選択結果を再読込みできる。
- 音声ファイルと動画指定区間、失敗時の後片付けを自動テストで確認した。全20テストが通過した。固定済み Windows ECAPA 環境では実モデルから192次元の有限値を生成し、Windows の画面構築も確認した。本人／他者判定の品質は Issue 06 の確認対象とする。
