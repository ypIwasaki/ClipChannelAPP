# 16: 登録情報の非表示・削除と動画の可逆保管を扱う

**GitHub Issue:** https://github.com/ypIwasaki/ClipChannelAPP/issues/16

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

**What to build:** 利用者が不要な一覧項目を整理し、元動画を保持して保管・展開できる。

**Blocked by:** 01: データ用フォルダを選んで既存データを開く; 02: ローカル動画を登録する

**Status:** ready-for-agent

## 完了条件

+- [ ] 登録情報の非表示・再表示ができ、保存済み結果から参照中の情報は削除を止める。実ファイル削除は別操作にする。
- [ ] 可逆保管・展開で元ファイルを無断で削除せず、圧縮前後のサイズと削減できなかった場合の結果を示す。
- [ ] 通常ログを30日で整理し、復旧待ちの処理に関係するログは期限だけで削除しない。
