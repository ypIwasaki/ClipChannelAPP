# 初版の一連の制作：機能別仕様

**参照元:** `docs/implements/spec-for-issues.md`（統合仕様書）

この機能群は、一人の利用者が元動画を取得または登録し、対象話者の文字起こし、頻出語・区間確認、AviUtl2での字幕・補助素材編集、明示保存、完成動画出力まで進める初版の経路を扱う。実装前の製品本体は存在せず、各 Issue の完了を同じ素材による一連の制作の完了とは区別する。

## 入力と成果

- 入力：認証不要のURLまたはローカル動画、人物と参照音声、利用者の区間・編集操作。
- 成果：元動画、版付きCSVの解析結果、編集用動画、AviUtl2プロジェクト、完成動画。
- データ用フォルダは直接接続されたWindowsドライブに置く。共通設定と解析結果はCSV、参照音声と特徴データは別ファイルにする。

## 境界

- 1回の編集で切り抜き元動画は1本。工程は利用者が選んで実行し、通常のトリミングに解析を必須としない。
- 元動画、旧版の解析結果、旧編集を暗黙に上書きしない。
- 初版から外す項目は統合仕様書の「初版から外す範囲」に従う。SQLite、外部編集CSVの取込み・修復、編集データの自動復旧、過去編集のアプリ内一覧などを追加しない。
- 未確定のCSV表現、時刻・媒体、話者品質、AviUtl2連携、中止・出力判定は、関係するIssue内で実装時に確認する。

## 完成確認

同じ素材で取得または登録から完成動画出力までを通し、各工程の入力・期待値・実結果・成果物・未検証範囲を記録する。個別機能の確認も統合仕様書に挙げられた既存の完成確認例に沿って行う。
