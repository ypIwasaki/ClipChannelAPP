## 条件

- シーン320×180 / 30fps / 44.1kHz、初期全長12秒。
- 同一補正MP4から連続する4秒の映像A/B/Cを同じレイヤーへ配置。
- 各映像と同じ時刻の字幕A/B/Cを別レイヤーへ配置。
- Aと同時刻に縮小画像1個。
- 2〜10秒のWAV1個、音量15%。クリップ境界をまたぐ補助音声の配置確認用。既存の発話音声であり、新しいBGM素材や音楽の聴感評価ではない。
