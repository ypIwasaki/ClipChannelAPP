## 仮定・提案のままの事項

現時点では検討用の仮定であり、この仮定に基づく実装は行っていない。

- AviUtl2と選定プラグインで要求編集・未保存状態の復元をすべて満たせること。SDKに編集入口があるだけでは成立を確認できない。
- BGM入りの人物素材で特徴照合が利用可能なこと。A86により初版の第一候補は特徴登録＋照合であり、追加学習は採用決定でも必須条件でもない。
- 全採用ツールをWindowsで動かせること。A44は条件付きでありWindows単独構成の決定ではない。faster-whisper、特定GUI、SQLite等も候補のまま。
- 「アプリ共通」の範囲はA58で解消済み。各データ用フォルダ内の全動画で共有する。
