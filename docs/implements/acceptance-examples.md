# 完成確認の固定例と証跡台帳

A104までの例を2026-09-24の編集・話者処理の合意に合わせて更新した、初版の確認用期待値。テストコード・完成確認用の動画・製品DB・編集プロジェクトは作っていない。下記の時刻と文章は設計上の例であり、指定済み動画を視聴して採録した内容ではない。原本AC/M番号を維持し、確認項目の無制限な追加を避ける。

## M-07：集計の固定文章

登録語は「ゲーム」「ゲーム大会」。対象話者の発言を次の2件とする。

| 発言ID | 元時刻 | 本文 |
| --- | --- | --- |
| U1 | 10〜12秒 | ゲーム大会、ゲーム大会。 |
| U2 | 20〜22秒 | ゲーム大会。 |

| 操作 | 期待値 |
| --- | --- |
| 除外語なしで集計 | 「ゲーム大会」3回、「ゲーム」0回。該当発言一覧はU1・U2の2件 |
| 「ゲーム大会」を選択 | U1=10〜12秒、U2=20〜22秒を表示。各項目から動画の該当箇所を確認可能 |
| 「ゲーム大会」を除外して再集計 | 両語とも0回。元の本文・字幕を削除しない。旧集計結果を暗黙に置き換えない |
| U2を対象者の発言から除外して別集計 | 除外語なしなら「ゲーム大会」2回、発言一覧はU1のみ |

活用の確認は、動詞を集計対象にした固定文章「走った。」「走る。」で基本形「走る」計2回を期待例にする。意味が似ている別語や登録していない表記違いをこの例から統合しない。解析器・辞書の実出力は未確認で、上記が既に動くとは扱わない。

## M-03：区間と字幕の固定時刻

元動画の長さを60秒とする説明用の例。

| 操作・条件 | 期待値 |
| --- | --- |
| 発話10〜20秒に前後各5秒 | 初期クリップ範囲5〜25秒 |
| 手で7〜23秒へ修正 | 出力指定7〜23秒。余白を再加算しない |
| 対象発言6〜8秒を取り込む | クリップ内字幕0〜1秒。本文は保持 |
| 対象発言22〜24秒を取り込む | クリップ内字幕15〜16秒。本文は保持 |
| 対象発言23〜24秒 | 半開区間を使う設計案では7〜23秒と重ならず、取込み対象外。内部の端点規則の期待値として明示 |
| 10〜20秒と25〜30秒を区間結合 | 10〜30秒。間の5秒も含む |
| 余白だけ重なる2候補 | 自動結合せず2候補として保持 |
| 30fpsで開始7.010秒を指定 | 適用7.000秒、差−0.010秒を確認可能。実出力の一致は別途照合 |

この例は一つの確認の入力変更であり、全境界値の組合せ試験を要求しない。字幕の開始・終了は適用した最終範囲から算出し、元時刻を失わない。

## M-04：対象話者の指定と手修正

今後の動作確認には今回の変幻リメ素材と別の動画を使い、参照音声を登録して対象話者を選ぶ。短い「対象者のみ」「他者のみ」「声が重なる」の区間を利用者の試聴で記録し、発話の有無と時刻の期待値を固定する。声の重なりは対象者が含まれるかも区別して記録できるときだけ、対象者の正解ラベルとして扱う。

| 確認する操作 | 期待値 |
| --- | --- |
| VAD・人物特徴の照合・文字起こし | 入力動画、参照音声、モデル版、区間時刻、スコア、発言を結びつけて保存・表示する。照合不能な区間を推測で対象者の発言に確定しない |
| 対象者／他者／不明の確認 | 試聴し、他者のみの発言を対象話者の成果物から除外できる。不明と重なりは人が対象発話／非発話へ修正できる |
| 発言の修正 | 認識漏れを時刻付きで追加し、他者混入を除外できる。元の認識結果と修正結果を区別して開き直せる |

今回の8区間は「他者のみ」2件・「声が重なる」6件で、対象者のみの正解例がない。[参考値](multi-speaker-validation.md)を新素材の閾値に流用しない。認識品質・修正量・処理時間に数値の合格上限を設けない。完成確認では対象者を選び、手修正を含む成果物を保存・再表示できること、状態表示と中止操作を確認する。全文修正が必要になっても、その量だけで不合格にしない。

## M-09：一本化後の順番変更と補助素材

同一元動画からA=0〜10秒、B=20〜30秒、C=40〜50秒の各10秒を使い、編集用MP4の画質はこの元動画を上限にする説明用の例。Bの対象話者の発言は元動画22〜24秒。A→B→Cを最初の編集用動画として生成する。

| 確認する操作 | 映像・字幕の期待値 | 編集と補助素材の期待値 |
| --- | --- | --- |
| 最初の編集用動画A→B→Cを生成 | 動画は30秒のMP4で、名前の例はA1_B2_C3.mp4。完成動画の出力初期値を基準にし、元動画と異なる数値設定は元動画を優先して生成する。Bの字幕は編集用動画の12〜14秒。一本の動画と編集可能な字幕をAviUtl2へ渡す | この動画に対応する編集を開き、画像・BGM・効果音を動画に紐づけて配置できる |
| この編集でBGMを5秒から30秒間配置し保存・出力 | 映像の終端は30秒 | BGMの設定長は30秒のまま。30秒以降にはみ出す音は完成動画に書き出さない。明示保存と出力の簡易完了判定を確認する |
| アプリ側で順番をB→A→B→Cへ変えて再生成 | 別の40秒MP4を生成し、名前の例はB2_A1_B2_C3.mp4。Bの発言字幕は最初2〜4秒、後半22〜24秒に別々に配置する | 元の30秒動画と旧AviUtl2プロジェクト・編集済み字幕・補助素材の配置は保持。新しい動画の編集は別物として管理し、旧編集の配置・修正を自動移行しない |
| 新しい編集へ補助素材を追加 | 映像と字幕の時間軸は40秒動画に合わせる | 新しい編集用動画に紐づく新規配置として保存できる。共有する補助素材ファイル自体は、旧編集を残したまま引き続き参照できる |
| 同じA→B→Cを再生成 | 名前は同じA1_B2_C3.mp4でも、編集ごとの別フォルダへ新しい動画を作る | 元の30秒動画・旧プロジェクト・字幕修正・補助素材配置を上書きせず、利用者は使う編集用動画をファイルから選べる |

AviUtl2内でA・B・Cの映像クリップを並べ替えたり、親クリップの移動・複製・削除に補助素材を追従させたりする旧例は、初版の完成条件から外す。本アプリからのUndo/Redoと手編集後の履歴整合、保存→出力の競合防止、途中失敗の自動復旧も今回の確認対象から外す。動画結合、字幕時刻・件数・本文・配置、映像と音声の継ぎ目、一本化した動画と字幕の受渡し、画面設定、保存・出力の簡易判定は実装時と結合テストで確認する。元動画の切り出し区間の編集・自動保存は編集プロジェクトの明示保存と区別する。

## M-08：保存済みデータとフォルダ切り替え

初版はデータ用フォルダを利用者が指定する。各フォルダには登録語・除外語・名前付き話者をCSVで保存する。解析結果は `catalog/<元動画名>/` の文字起こし・区間一覧・頻出語集計の種類別フォルダへCSVで保存し、再解析では `_vN` を進めて旧版を保持する。参照音声・人物特徴等の実体は別ファイルとする。

| 操作 | 期待値 |
| --- | --- |
| 既存フォルダF1で結果を保存し、別の既存フォルダF2へ切り替える | F2の登録・保存済み結果を表示し、F1の内容を書き換えない。実行中処理や未保存入力があれば切り替えを止める |
| F1へ戻す | F1の人物・辞書・結果と旧版を再表示できる。切り替えによって複製・統合しない |
| 別の元動画と同名のファイルを登録する | 警告し、区別できる名前へ変更するまで新規登録・解析しない。既存動画の再解析なら次の `_vN` を作る |
| 編集を開き直す | 利用者がAviUtl2プロジェクトを直接選ぶ。必要な動画・補助素材は利用時に選択し、アプリ内の編集一覧や参照先の自動再接続に依存しない |
| 参照中の登録情報を削除する | 保存済み解析結果が参照する人物・辞書・結果は削除を止める。実ファイル削除は別操作にする |

同一PC内の複製・取り込み、別PC引き継ぎ、編集データ自動復旧を初版の合格条件にしない。従来のDB複製・ZIP移行の固定例は旧設計の検証履歴として[保存案](storage-transfer-validation-proposal.md)に残す。ログの30日整理は維持するが、見送った編集復旧の状態と復旧用情報を新たに作る条件にはしない。

## 実素材の未準備を明示する

| 原本素材 | 現在の状態 | 後の準備で必要な情報 |
| --- | --- | --- |
| M-01 / M-02 | 原本指定の約1時間／約7時間のURLを維持。取得・視聴・実長確認なし | 実形式、長さ、対象話者、確認する区間、取得条件 |
| M-03 / M-04 | M-03の数値例とM-04の確認方法は準備済み。今回の8区間は他者のみ2件・重なり6件で、対象者のみの正解例はない | 今後使う別動画で対象者のみ・他者のみ・重なりの短区間と参照音声を固定。文章品質をAI採点する要件は追加しない |
| M-05 | 約10時間の実素材・方法は未選定 | 実長、チャンク境界、処理時間・メモリ推移、中止の記録。7時間成功で代用しない |
| M-06 | 認証不要・SDR・音声1本の通常素材を初版対象とする | 取得と変換後の形式・時刻・音声同期を記録。HDR・用途別複数音声・配布環境を初版の必須確認に戻さない |
| M-07 | 本書で固定文章と期待値を準備 | 採用辞書と実出力の照合 |
| M-08 / M-09 | フォルダ切り替え・同名動画の保護と、一本化・別編集管理の期待値を準備。実体なし | 保存形式と編集プロジェクトを後の実装・検証段階で用意 |
| M-10 | 圧縮物・展開物は未準備 | 元と展開物のハッシュ一致、双方保持、未削減時表示 |

実素材の未確認箇所を今回の例文・数値で埋めたとは記録しない。素材選定で対象者等の利用者判断が必要になれば、その時点で不足情報を具体的に尋ねる。

## 証跡の単位と完成判定

将来の各確認記録には、対応AC、使用素材と区間、対象版・モデルrevision・設定、期待結果、実際の結果、操作キャプチャ、出力・保存先、未検証範囲を載せる。成果物には参照先を記録し、認証値・認証入りURL・生のコマンド全文を保存しない。

状態は「未準備」「確認可能だが未実行」「確認済み」「不一致」「対象外（根拠となる合意）」を区別する。資料上の機能だけでは確認済みにしない。認識の全文修正や長い処理時間そのものを不合格にはせず、対象話者指定の実処理・手修正・状態表示・中止を確認する。

模擬失敗の基本上限は利用者合意どおり計3件とする。ただし、従来の第3件だった編集の途中失敗からの自動復旧は今回見送ったため、初版の必須確認に含めない。旧成果物保護と失敗時の入力保持は各1件の例を維持し、代わりの失敗ケースを無断で追加しない。通常操作の期待例と失敗条件を掛け合わせない。
