# 完成確認の固定例と証跡台帳

A104までの合意に基づく確認用の期待値。テストコード・動画・DB・編集プロジェクトは作っていない。下記の時刻と文章は設計上の例であり、指定済み動画を視聴して採録した内容ではない。原本AC/M番号を維持し、確認項目の無制限な追加を避ける。

## M-07：集計の固定文章

登録語は「ゲーム」「ゲーム大会」。対象話者の発言を次の2件とする。

| 発言ID | 元時刻 | 本文 |
| --- | --- | --- |
| U1 | 10〜12秒 | ゲーム大会、ゲーム大会。 |
| U2 | 20〜22秒 | ゲーム大会。 |

| 操作 | 期待値 |
| --- | --- |
| 除外語なしで集計 | 「ゲーム大会」3回、「ゲーム」0回。該当発言一覧はU1・U2の2件 |
| 「ゲーム大会」を選択 | U1=10〜12秒、U2=20〜22秒を表示。各項目から動画の該当箇所を確認可能 |
| 「ゲーム大会」を除外して再集計 | 両語とも0回。元の本文・字幕を削除しない。旧集計結果を暗黙に置き換えない |
| U2を対象者の発言から除外して別集計 | 除外語なしなら「ゲーム大会」2回、発言一覧はU1のみ |

活用の確認は、動詞を集計対象にした固定文章「走った。」「走る。」で基本形「走る」計2回を期待例にする。意味が似ている別語や登録していない表記違いをこの例から統合しない。解析器・辞書の実出力は未確認で、上記が既に動くとは扱わない。

## M-03：区間と字幕の固定時刻

元動画の長さを60秒とする説明用の例。

| 操作・条件 | 期待値 |
| --- | --- |
| 発話10〜20秒に前後各5秒 | 初期クリップ範囲5〜25秒 |
| 手で7〜23秒へ修正 | 出力指定7〜23秒。余白を再加算しない |
| 対象発言6〜8秒を取り込む | クリップ内字幕0〜1秒。本文は保持 |
| 対象発言22〜24秒を取り込む | クリップ内字幕15〜16秒。本文は保持 |
| 対象発言23〜24秒 | 半開区間を使う設計案では7〜23秒と重ならず、取込み対象外。内部の端点規則の期待値として明示 |
| 10〜20秒と25〜30秒を区間結合 | 10〜30秒。間の5秒も含む |
| 余白だけ重なる2候補 | 自動結合せず2候補として保持 |
| 30fpsで開始7.010秒を指定 | 適用7.000秒、差−0.010秒を確認可能。実出力の一致は別途照合 |

この例は一つの確認の入力変更であり、全境界値の組合せ試験を要求しない。字幕の開始・終了は適用した最終範囲から算出し、元時刻を失わない。

## M-09：ハイライト編集と補助素材の固定配置

同一元動画からA=0〜10秒、B=20〜30秒、C=40〜50秒の各10秒クリップを使う。初期配置はA→B→C、完成タイムラインは0〜30秒。Bの字幕は元動画22〜24秒、初期タイムライン12〜14秒。Aに紐づくBGMはA開始から5秒後に開始し、長さ30秒。

| 操作 | 映像・字幕の期待値 | BGM等の期待値 |
| --- | --- | --- |
| Bを複製して冒頭へ挿入 | B複製0〜10、A10〜20、B20〜30、C30〜40秒。複製字幕2〜4秒、本編字幕22〜24秒 | Aに紐づくBGMは15〜45秒へ移動し、長さ30秒を維持。出力は最後の映像が終わる40秒まで |
| 複製字幕の本文・効果を修正 | 本編Bの字幕・効果は変わらない | 複製対象として選んだ補助素材だけが独立配置になる |
| この状態からAを削除 | B複製0〜10、B10〜20、C20〜30秒。本編B字幕12〜14秒 | Aに紐づくBGM配置は削除。音声ファイル自体は保持 |
| A削除を元に戻す／やり直す | 映像と字幕を一操作の前後へ一致させる | BGMの関連配置も同じ履歴単位で復元・削除する |

保存・再開、外部手編集との履歴境界、出力中の編集待ちは同じ固定プロジェクトへ対応付ける。[編集E1〜E5](editor-integration-gates.md)とは別のテスト群を増やすのではなく、共通素材と証跡を使う。

## M-08：引き継ぎと削除の確認データ案

人物P1、参照音声R1、人物特徴V1、元動画S1、文字起こしT1と手修正済みT2、区間一覧L1/L2、保存済み編集E1を関連付ける。実DBは未作成。

- 引き継ぎ後もT1/T2・L1/L2を選べ、参照関係を維持する。参照音声・人物特徴・保存済み編集は実体も含む。
- 別途移動する動画・補助素材が不在でも情報は残す。再接続後に必要な処理を利用可能にする。
- 共通モデル未準備でも取り込みと保存済み情報の閲覧は可能。照合のみ未準備と表示する。
- E1等から参照中の情報は削除を止める。非表示→引き継ぎ→再表示後も参照が維持される。
- A94の通常ログ30日整理で、復旧待ちの関係ログ・復元情報と素材・保存済み成果物を消さない。時刻条件を扱う確認であり、故意の破損試験を追加しない。

## 証跡の単位と完成判定

将来の各確認記録には、対応AC、使用素材と区間、対象版・モデルrevision・設定、期待結果、実際の結果、操作キャプチャ、出力・保存先、未検証範囲を載せる。成果物には参照先を記録し、認証値・認証入りURL・生のコマンド全文を保存しない。

状態は「未準備」「確認可能だが未実行」「確認済み」「不一致」「対象外（根拠となる合意）」を区別する。資料上の機能だけでは確認済みにしない。認識の全文修正や長い処理時間そのものを不合格にはせず、対象話者指定の実処理・手修正・状態表示・中止を確認する。

模擬失敗は既存の3件（旧成果物保護、入力保持、未保存を含む編集復元）のまま。通常操作の期待例を用意したことを理由に、失敗条件を各例へ掛け合わせない。
