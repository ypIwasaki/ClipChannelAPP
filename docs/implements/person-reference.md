# 人物と参照音声の保存契約

Issue 05 の登録では、データ用フォルダの `people/people.csv` に人物 ID・名前・参照音声・特徴ファイルへの相対パスを保存する。参照音声は `people/<人物ID>/reference.wav`（16 kHz、単声道 PCM）、特徴と設定は `people/<人物ID>/feature.json` に保存する。対象動画と人物 ID の選択は `people/targets.csv` に保存する。人物を追加しても既存の人物・参照音声は上書きしない。

音声ファイルはそのまま選択できる。動画から登録する場合は、データ用フォルダに登録済みの動画と開始・終了秒を指定する。元音声・元動画は変更しない。参照音声の試聴には `ffplay`、音声変換には `ffmpeg` を使う。これらやモデルの依存物が不足していても、保存済みの人物 CSV は閲覧できる。

特徴生成の候補は、既存の[Windows連携条件](speaker-integration-gates.md)で実測済みの SpeechBrain 1.1.1 ECAPA、ローカル配置モデル、CPU、16 kHz 単声道、`encode_batch(normalize=False)` とする。モデル取得は登録処理では行わず、ローカルモデルフォルダを利用者が指定する。特徴は192個の有限値として保存し、モデルファイル群の SHA-256 と前処理を記録する。参照音声全体か5秒窓の平均を利用者が選ぶ。

照合閾値は登録時に -1〜1 の cosine 値を明示指定する。実測資料には本人確認済みの別動画例があるが、他者や重なりを含む正解例が不足しているため、アプリの既定閾値は定めない。この値を使う判定品質は Issue 06 の短区間確認で評価する。登録と動画ごとの対象話者選択は、その品質判定とは分けて保存・再表示する。
