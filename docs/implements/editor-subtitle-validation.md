# 日本語・改行入り字幕の保存と再読込み

2026-09-18、A105の限定検証許可と継続指示に基づく実測。分離済みAviUtl2 2.1.9を使用し、追加プラグインは導入していない。

## 実施と結果

前回のnormal-operations.aup2を別名subtitle-roundtrip.aup2へコピーし、標準テキストの入力欄へ次の本文を画面から入力した。

```text
検証用字幕：変幻リメ
2行目：保存・再読込み確認
```

プレビューで日本語2行の表示を確認して保存。保存ファイルのテキスト項目にも同じ本文とエスケープされた改行（リテラルの `\n`）が記録されていた。オブジェクトのframe=59,139は変更されていない。

通常終了して対象ウィンドウがなくなったことを確認した後、新たにエディターを起動して同ファイルを開いた。カーソル3.30秒で同じ2行がプレビューへ戻り、Layer1の標準テキストオブジェクトとして選択されていた。確認後に通常終了した。再読込み後の本文変更は試していない。

[保存ファイル](evidence/editor-normal/subtitle-roundtrip.aup2)は1,461 bytes、SHA256 `9FFC5DB9F7C89858FB81A3DCF8B65A5BF86BC7AAFD4AE3758546E9C9EA528EB8`。検証用の絶対パスを含むため、別環境のパス解決は今回の検証対象外。

元のnormal-operations.aup2のSHA256は `01B1A5C8905FECF05F88D9D02D50D0827E2CD8A559910BF676D89E18451EB7B0` のまま。元仕様spec-legacy-v0.1.mdも既存のSHA256から不変。

## 判定と残件

E2のうち、標準テキスト1個の日本語本文・改行の保存とプロセス再起動後の表示を部分確認した。ASR結果からの自動取込み、字幕時間の切詰め、複製後の独立編集、映像・BGM・効果を含む複合状態、アプリ側の保存世代との一致は未検証。保存形式の直接生成やUI操作を製品の連携方式として採用する判断ではない。

E3の複合操作履歴、E4の排他・出力、E5の未保存編集を含む復元は残る。模擬失敗確認は追加実施していない。製品要件の変更、本体実装、仕様確定、Issue分割は行っていない。
