## 判定と残件

E2の専用データ保存・読戻し、E3の更新通知を部分実証した。保存直前通知は依然として保存成功通知ではない。今回の成功判定は保存実体の確認と再読込みを合わせたものであり、エラー時の検出や他者による同時変更を扱っていない。

手動移動とUndoは同じ更新通知で、イベントには操作元・操作IDがない。アプリ経由の変更はまだ実行しておらず、通知を受け取れたことを手編集境界の完成と扱わない。専用プラグインからの編集・原子的な変更単位・出力排他・機械的な終了通知・未保存状態を含むE5復元は残る。故意の失敗は注入せず、3件の模擬失敗枠を消費していない。次は検証専用のSDK編集セクションで、変更単位と状態の読戻しを観測する段階になる。
