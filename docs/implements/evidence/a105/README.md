# A105の保存証跡

一時フォルダの整理で検証根拠が失われないよう、実行済みの最小コード、結果、依存版、モデル指紋、編集UIの観測抜粋を保存した。コピー時に話者側5ファイルのSHA256一致を確認した。モデル重み・Python環境・人工特徴ファイルは同梱していない。

検証の条件と限界は [話者結果](../../a105-speaker-validation.md)・[編集結果](../../a105-editor-validation.md)を参照。

`speaker/probe.py` は実行当時の原本。直接このディレクトリで実行しない。再実行時は別の検証領域へコピーし、文書に記録した環境、固定revisionのmodel一式、revisionを持つmodel-api.jsonを用意する。依存版一覧は観測記録であり、全配布物のハッシュを固定したインストーラーではない。

人工波形で話者識別の精度を確認した記録ではない。編集メニューの存在を保存・出力・復元の成功と扱わない。
