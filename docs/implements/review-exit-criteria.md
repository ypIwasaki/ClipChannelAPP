## 保存契約の具体案（未実装）

保存担当は、実行結果と永続化の完了を区別する。次の状態名は内部設計の提案であり、新しい利用機能ではない。

| 状態 | 意味 | 再開・復旧時の扱い |
| --- | --- | --- |
| 作業中 | 入力・旧成果物を保持した処理専用領域へ生成中 | 所有する生成物だけを未完成として識別。処理本体を自動再実行しない |
| 検査済み | 新規成果物の内容確認が済み、登録は未完了 | 内容・入力版を照合し、確定処理を再開できる候補として表示 |
| 確定待ち | 出力先と置換対象、旧成果物の保護先が記録済み | 既存確認の対象が変わっていれば確認をやり直す。推測で上書きしない |
| ファイル確定・DB未確定 | 新ファイルはあるが、利用可能な結果としてDBに登録できていない | 未登録結果として保持し、入力・内容指紋・関係を確認して登録のみ再試行する案 |
