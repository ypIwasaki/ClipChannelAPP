# AviUtl2の不足をプラグインで補う

別の編集基盤を用意せず、AviUtl2を前提に不足分をプラグイン作成で補う（2026-09-18、A85）。MLT等への置換・併設より、選定した編集環境を拡張する方向を選び、それでも実装が困難な機能は根拠と影響を示して個別に採用を再検討する。これは実現可能性の確認や実装開始の承認ではなく、ADR-0003の未確認操作の実行停止・復元条件は維持する。

2026-09-18追記：今回の実装範囲について、保存→出力の競合防止と途中失敗からの復旧を必須条件とする部分は [ADR-0006](0006-defer-edit-race-protection-and-recovery.md) により変更された。上記本文は従来の判断履歴として保持する。
