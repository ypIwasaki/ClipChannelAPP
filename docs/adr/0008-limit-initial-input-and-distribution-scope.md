# 実取得に不要な認証・特殊入力・配布対応を初版から外す

2026-09-18、利用者は既存2動画のダウンロードに関係しない認証付き取得・特殊入力・配布環境の対応を、初版実装と必須検証から外すと決定した。2本とも認証なしのSDR・音声1本で、現在のローカル実行環境から取得できていたため、認証入力、HDR変換、用途別複数音声選択、配布パッケージと別環境配布検証を見送る。広範な対応を先に作るより、実際に使う通常経路と話者処理を優先する。

この判断はA95/A100/A102/A103等の初版範囲を縮小する。実行に必要なツール・モデルの別途準備や不足時の処理停止、実素材で生じた時刻ずれの補正、編集互換変換は維持する。除外と維持の根拠は [実取得に基づく範囲判定](../implements/initial-scope-pruning.md) を参照する。元仕様と過去の証跡は保持し、仕様全体の確定や製品実装の開始には進まない。
