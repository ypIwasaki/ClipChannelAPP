# 初版のDB管理を話者・共通設定・解析結果に限定する

2026-09-24、利用者はテーブルと管理方法の複雑化を避けるため、素材、編集、処理と出力をDB管理から外すと決定した。初版のDB候補は話者・共通設定・文字起こし／区間／集計などの解析結果に限定し、素材・編集・処理／出力は通常ファイルと必要最小限のファイル単位の情報で扱う。編集データの復旧機能も初版から外す。原本仕様と旧保存案は判断の経緯として残し、この決定を優先する。

編集用動画とAviUtl2プロジェクトの別フォルダ保存、明示保存、保存・出力の簡易完了判定、区間操作の自動保存、失敗した解析入力の保持と手動再試行は、DB管理や編集データ自動復旧とは別の動作として維持する。素材と解析結果の対応方法、編集用動画とプロジェクトの対応方法、引き継ぎ形式および失敗時に残ったファイルの扱いは、DBテーブルを再導入する前提を置かず実装前に具体化する。

2026-09-24追加合意：初版は過去の編集を本アプリ内で一覧・選択して再開する機能を設けず、利用者がAviUtl2プロジェクトを直接選んで開く。編集用動画とプロジェクトの対応をアプリ側の台帳で保持する必要はない。別フォルダ保存と旧編集保持は維持する。参照先の動画・補助素材が移動した場合は利用者がファイルを選んで対応し、初版のアプリ側に参照先の自動再接続・修正機能は設けない。

2026-09-24追加合意：解析結果をファイルとして保存する際は、元動画の拡張子を除いたファイル名を流用する。初回は末尾に `_v1`、再解析した結果は `_v2`、`_v3` と番号を進め、旧結果を上書きしない。例：`sample.mp4` に対し `sample_v1`、再解析では `sample_v2` を結果ファイル名の基部に使う。同名の別素材、結果種別ごとの衝突と拡張子の扱いは実装時に決める。

2026-09-24追加合意：別PCへ作業データを引き継ぐ機能は初版から外し、後続検討とする。同一PCの別データ用フォルダへの取り込み・切り替えは従来の合意として残す。A89・A90・A93等に基づく別PC向けパッケージ内容や移行先環境の互換性確認は初版要件としない。

2026-09-24追加合意：編集用動画・補助素材は利用者が利用時にアプリ側から選ぶため、初版のアプリは移動後の参照先を保持しない。人物情報に対する参照音声・人物データの移動後参照も保持しない。解析結果は元動画1本ごとに作り、複数動画を一つの解析結果へまとめない。元動画と結果の恒久的なパス対応台帳は作らない。別の元動画が同じファイル名を持つ場合、`_vN` の名前だけでは同一性を区別できない。

2026-09-24追加合意：同じデータ用フォルダで既存の元動画と同じファイル名を持つ別動画を選んだ場合、警告を表示し、名前を変更するまで新しい動画の登録・解析を進めない。既存動画の再解析は同名衝突として扱わず、版番号を進める。利用者が区別できる名前を付けることを求め、アプリが別動画の結果を既存動画の`_vN`へ混ぜたり上書きしたりしない。

2026-09-24追加合意：同一PC内でデータ用フォルダを複製・取り込む機能も初版から外す。利用者が既存のデータ用フォルダを指定して使用先を切り替える操作のみ維持する。前段の「同一PCの別フォルダへの取り込み・切り替えを残す」という記録は、取り込みを含める部分をこの判断で変更する。ファイル群のコピー範囲や移行パッケージ形式を初版のために決める必要はない。

2026-09-24追加合意：解析結果は元動画名（拡張子を除く）と同名のフォルダを作り、その下で文字起こし・区間一覧・頻出語集計を種類別フォルダに分けてファイル保存する。各結果の基部名には従来どおり `_v1`、再解析時は `_v2` 以降を用い、旧版を保持する。これにより前段の「解析結果もDB候補」という部分を変更し、DB候補は人物・登録語・除外語などの共通設定に限定する。結果ファイルの拡張子・内部形式は未固定。

2026-09-24追加合意：文字起こし・区間一覧・頻出語集計の結果ファイル、および人物・登録語・除外語などの共通設定はCSV形式で保存する。前段に残したDB候補は初版から外す。参照音声や人物特徴・モデルなどのバイナリ実体までCSVへ変換する意味ではなく、通常ファイルとして別に保持する。CSVの列構成・符号化・時刻表現は実装時に定める。
