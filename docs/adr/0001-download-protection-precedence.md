# yt-dlpの追加引数よりアプリの保存・保護ルールを優先する

yt-dlpの全機能への入口を主要設定GUIと追加引数欄で提供するが、アプリの保存・入力保持・上書き確認などの保護条件に反する指定は制限する。衝突は実行前に理由を示して利用者に修正を求め、引数を黙って無視・変更しない。任意指定を無条件に受け付ける方式では固定の保護契約を守れないため、この境界を採用する（2026-09-17、仕様再検討A9で合意）。

A99で、初版の任意外部コマンド・追加プラグイン実行は、保存・中止・秘密値保護を確認できた個別連携に限定すると合意した。一般的な任意コード実行より保護条件を維持できる範囲を選び、非対応の理由を機能案内へ表示する。全CLI機能という原本の要求をこの範囲で見直すが、通常の形式・品質設定まで縮小する判断ではない。
