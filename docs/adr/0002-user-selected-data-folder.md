# 利用者がデータ用フォルダを指定する

動画の保存先を開発リポジトリ内に限定せず、利用者がデータ用フォルダを指定できるようにする。ローカル動画のコピー、変換前動画、圧縮物などを保持するため、容量に応じた保存先を選べることを優先する（2026-09-17、仕様再検討A31で合意）。内部の配置規則と利用開始後の移動方法は未確定であり、運用データをGit管理対象外とする方針は維持する。

初版の指定先はWindowsから直接使う内蔵・外付けドライブとし、NAS・ネットワーク共有・クラウド同期中のフォルダを対象外とする（2026-09-18、A87）。保存・復旧を確認する条件を限定するためであり、開発用リポジトリの所在や話者処理のWSL利用を制限する判断ではない。

2026-09-24追加合意：利用者指定のデータ用フォルダの直下は `catalog/`、`media/`、`people/`、`projects/`、`exports/`、`archives/`、`work/`、`recovery/`、`logs/` に分ける。編集用MP4は `media/edits/<編集フォルダ>/`、対応するAviUtl2プロジェクトは `projects/<編集フォルダ>/` に置き、編集ごとに別フォルダとして旧動画・旧編集を残す。上の当初記録にある「内部の配置規則は未確定」はこの範囲で解消した。具体的な内部フォルダ名、DB形式、移行パッケージ形式等は別途設計する。

2026-09-24追加合意：解析結果は `catalog/<元動画名>/` 以下に文字起こし・区間一覧・頻出語集計の種類別フォルダを設けて保存する。元動画名は拡張子を除いた名前で、各結果ファイルは版番号 `_vN` を持つ。元動画と同名の別ファイルは登録・解析前に警告して名前変更を求める。内部形式は別途設計する。
