# 利用者がデータ用フォルダを指定する

動画の保存先を開発リポジトリ内に限定せず、利用者がデータ用フォルダを指定できるようにする。ローカル動画のコピー、変換前動画、圧縮物などを保持するため、容量に応じた保存先を選べることを優先する（2026-09-17、仕様再検討A31で合意）。内部の配置規則と利用開始後の移動方法は未確定であり、運用データをGit管理対象外とする方針は維持する。

初版の指定先はWindowsから直接使う内蔵・外付けドライブとし、NAS・ネットワーク共有・クラウド同期中のフォルダを対象外とする（2026-09-18、A87）。保存・復旧を確認する条件を限定するためであり、開発用リポジトリの所在や話者処理のWSL利用を制限する判断ではない。
