# 動画の順序をアプリ側で確定して一本化する

2026-09-18、利用者の提案と反映指示により、初版は本アプリで使用区間と順序を決め、AviUtl2へ渡す前に一本の編集用動画へ結合する。AviUtl2へは結合動画と、その時間軸に合わせた編集可能な字幕を渡し、複数の映像クリップを並べ替える連携を初版から外す。複雑なタイムライン操作の連携を減らす選択であり、結合の生成時間・容量が必要となり、取込み後の順序変更と補助素材の扱いは別途整理する。

字幕は焼込みにせず、プラグインから編集可能な字幕オブジェクトとして生成する。既存字幕のaliasから再生成できた実測を生成入口の根拠とし、複数生成は実装前の独立した成立検証にせず、本文・件数・時刻・配置を実装時にテストする。保存・履歴・出力制御の未確認部分まで成立済みとする判断ではない。

詳細な適用範囲と未合意事項は [初版の編集受渡し方針](../implements/editor-handoff-scope.md) を参照する。ADR-0006の競合防止・途中失敗復旧の見送り、および明示保存は維持する。

2026-09-24追加合意：一本化後に順番を変える場合は本アプリで組み直し、別の編集用動画を生成する。画像・BGM・効果音の配置は編集用動画に紐づける。これは旧来の個々のクリップへの紐づけ・追従方式を初版の編集経路では置き換える判断である。その後の利用者回答により、新しい編集用動画に対応する編集は、既存のAviUtl2プロジェクト・編集済み字幕・補助素材の配置と別物として管理する。既存編集の自動移行は行わず、元の編集を残す。
